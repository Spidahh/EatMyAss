# SPECIALIZZAZIONI V2 — TRE STILI FORTI SENZA QUATTRO BARRE SKILL

**La vecchia terna Assaltatore/Ingegnere/Soccorritore è SOSTITUITA** con specializzazioni scelte tramite terminale **dentro** la base; una skill Q e una passiva ciascuna, non classi che vietano genericamente il melee. Nessun healer obbligatorio, revive è universale.

| Ruolo | Passiva | Abilità Q | Dove dà valore |
| --- | --- | --- | --- |
| **Tiratore** | acquisizione bersaglio/ADS più stabile nei primi colpi dopo cambio nemico | **Bersaglio aperto**: marca weakpoint di un solo nemico per 5s; il prossimo colpo al punto debole ottiene bonus misurato, cd40s seed | contro elite fuori |
| **Spezzatore** | parry perfetta riduce stamina della risposta, permette contrattacco | **Rompiguardia**: prossimo heavy melee apre/rompe difesa fisica di 1 bersaglio normale/armored con cooldown, cd45s | melee strategico |
| **Tecnico** | upgrade base leggermente meno cari, 5% seed | **Disturbo mirato**: su elite esterno che chiama/sabota impedisce capacità speciale per 5s, cooldown50s | protegge indirettamente la base |

**Opzione “Mischia pura”** disponibile allo Spezzatore nel terminale: blocca volontariamente l'uso slot firearm per avere bonus di stamina/parry. Non si scelgono 12 perk; si può disattivare entrando dentro base, senza perdere armi possedute. Deve essere competitivo contro Armored e boss se skillata; ogni elite raggiungibile. Altre due classi possono sempre usare machete/mazza/asta.

Per ogni attiva: vero montage 1p/3p, SFX, VFX, anim interruption/recovery, hit/miss, server cooldown e target checks, UI icon Q e remote observer. Nessuna skill fa sparare torrette quando sei fuori: la torretta combatte da sola anche senza Tecnico. Non aggiungere dash, revive magicamente all screen, cooldown multipli, ultimates a catena.
