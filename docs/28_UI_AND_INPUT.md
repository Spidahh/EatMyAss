# UI/INPUT V2 — DUE CONTESTI, POCHI MENU

**Dentro base (upgrade, NON battaglia):** 4 terminali reali Armeria, Difese, Comando, Specializzazioni. Prompt E vicino al terminale e pannello a schermo con max 2–4 scelte/tier; disabilitato se player fuori base. Base appare come interno fisico realistico non city map manager. Mostra Rottami, costo, anteprima concreta upgrade, CoreHP, potenza-capacità, stadio, “Autodifesa: forte/media/a rischio” calcolata da dati misurabili, mai previsione finta. In coop acquisto grande conferma.

**Fuori (combattimento):** HUD personale HP/Stamina, arma/ammo, melee guard indicator, 1 icona Q specializzazione, stato obiettivo breve (max 1), allarme Base sotto attacco con posizione/vita senza obbligo tornare, indicatore ritorno entrata. La torretta combatte da sola, non richiede una barra “dirigi torre” o ping target. Stima allarme chiara: Perimetro stabile, Sotto pressione, Varco danneggiato, Nucleo critico, nessun urlo ogni 5s.

### Input mappabile

| Tasto | Fuori combattimento | Dentro base |
| --- | --- | --- |
| WASD/mouse | muovi e mira | muovi e guarda |
| LMB | spara/colpo melee | scelta UI quando terminale |
| RMB | ADS / blocco con melee | UI se terminale |
| R | reload se firearm | non necessario |
| Shift | sprint | sprint facoltativo |
| Ctrl | crouch | crouch |
| Space | salta | salta |
| 1/2/3 | seleziona arma/melee | equip solo presso Armeria o scorciatoie conformi |
| E | interazione evento fuori/cancello | apri pannello terminale |
| Q | unica skill della specializzazione | non cast skill nel terminale |
| Tab | stato pressione assalto/obiettivi | stato upgrade minaccia |
| Esc | pausa UI (non ferma server co-op) | chiudi terminale/menu |

**Nessun V-shove extra e nessun E manuale Core Pulse**: entrambi ritirati nella V2. Il Core Pulse è automatico. Parry usa tap RMB 0,20s senza un input in più. Opzioni accessibilità rebind, camera shake slider, FOV, subtitle allarme, UI scaling, no flash eccessivi.
